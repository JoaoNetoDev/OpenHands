## Root cause of the original Sonnet bug

User attached `claude-skills-2026-09-15.zip` via the OpenHands Canvas chat
composer. The LLM received only the file **basename** (`claude-skills-2026-09-15.zip`)
because the upload API discarded the workspace-relative path. Sonnet ran
`find / -maxdepth 6 -iname '*claude-skills-2026-09-15*'` and got nothing тАФ the
zip was at `/home/openhands/workspace/project/.../claude-skills-2026-09-15.zip`
but only the basename reached the conversation.

## Workspace com mesmo nome (`public_html`) — desambiguação

Pedido do usuário: dois workspaces chamados `public_html` (clientes diferentes)
apareciam idênticos no seletor.

- `src/utils/workspace-display.ts::getWorkspaceSecondaryLabels()` mapeia
  `workspace.id -> diretório-pai` **somente** quando o nome colide; nome único
  devolve `null` (linha continua simples). O `DropdownItem` ganhou
  `getSecondaryText` e o `WorkspaceDropdown` mostra a mesma linha no controle
  fechado (`data-testid="selected-workspace-directory"`).
- **Bug pego no probe Playwright**: a primeira versão preferia
  `workspace.parentPath`. Workspaces vindos de um *workspace parent* (varredura
  de uma pasta raiz) compartilham o MESMO `parentPath`, então as duas linhas
  viravam `/projects` — continuava ambíguo. O label tem que sair SEMPRE do
  `path` da própria workspace (`getPathDirectory(path)`), nunca do parentPath.
- `getPathDirectory()` foi extraído para `src/utils/path-utils.ts` (POSIX +
  Windows, `null` em raízes e nomes soltos) e o `getParentPath()` privado de
  `folder-browser-modal.tsx` agora delega a ele.
- Verificado no browser: `OPTION LABELS` viraram
  `"public_html, /projects/cliente-a"` / `"public_html, /projects/cliente-b"`,
  linhas de 52px vs 36px das linhas simples, label abaixo do nome e dentro da
  row, e o controle fechado mostra o diretório.
- Para testar isso no mock é preciso MOCKAR o `/api/workspaces` **e** o
  `/api/file/search_subdirs` (`src/mocks/file-service-handlers.ts`) — o dropdown
  agrupa pelos parents varridos, não pela lista estática. Ambos foram revertidos
  depois do probe.
- Suítes verdes: `path-utils`, `workspace-display`, `workspace-dropdown`,
  `workspace-selection-form`, `local-new-conversation-menu` (57 testes).
