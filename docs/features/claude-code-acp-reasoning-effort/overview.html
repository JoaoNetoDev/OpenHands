Reasoning effort para Claude Code no OpenHands

Visão executiva — sem jargão técnico

O problema

No Agent Canvas (OpenHands), já existe um botão para ajustar o "esforço de raciocínio" (quão a fundo o modelo pensa antes de responder) durante uma conversa. Esse botão funciona para alguns agentes de IA, mas não funciona quando a conversa está usando o Claude Code — mesmo o Claude Code já sendo capaz de receber esse ajuste, essa capacidade simplesmente não está conectada no OpenHands.

O que será entregue

  • Quando alguém configurar a conversa para usar Claude Code com um nível de esforço específico (baixo, médio, alto ou máximo), essa escolha passa a ser realmente aplicada.
  • Nenhuma tela nova é necessária — o mecanismo já existente é reaproveitado.
  • Nenhum outro agente (Codex, Gemini, etc.) é afetado.

Onda e sprint

Onda 1 — Sprint única
Mudança concentrada em um único arquivo do "motor" que conecta o OpenHands ao Claude Code. Baixa complexidade: o mesmo mecanismo já existe e funciona para outro agente (Codex) — aqui só se estende o mesmo caminho para o Claude Code, com o nome de configuração correto que o Claude Code espera.

Riscos

  • Baixo Os níveis de esforço aceitos pelo Claude Code podem variar por modelo/conta — se alguém pedir um nível que aquele modelo específico não aceita, o pedido é simplesmente ignorado (sem quebrar a conversa).

O que fica de fora

  • Não inclui os modos avançados de outro produto usado como referência (LionCode) que reescrevem o pedido do usuário para forçar mais raciocínio — só o ajuste "puro" de esforço.
  • Não inclui nenhuma mudança na tela do Agent Canvas — o botão já existe.
  • Não inclui suporte no backend Cloud (o botão já é restrito a conexões locais/próprias).
