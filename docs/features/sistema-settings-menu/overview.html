Sistema — novo menu de configurações

Primeiro de quatro pacotes de trabalho rumo ao board Kanban de planejamento de features. Este pacote entrega uma tela nova, "Sistema", onde a pessoa usuária define três coisas uma única vez: qual pasta de trabalho usar por padrão, qual modelo de IA usar por padrão, e um texto de contexto (nome do time, convenções, preferências) que os próximos pacotes vão reaproveitar.

O que muda para quem usa o produto

  • Uma nova opção "Sistema" aparece no menu de configurações.
  • Nela: escolher a pasta de trabalho padrão, escolher o modelo de IA padrão, escrever um texto de contexto com formatação simples (negrito, itálico, listas, links).
  • Esses três valores ficam salvos neste computador (não sincronizam entre máquinas nesta primeira versão).

Riscos

Sem sincronização entre máquinas. Se a pessoa usar o produto em dois computadores, precisa configurar os dois separadamente. Aceito conscientemente para entregar mais rápido; pode virar um pacote futuro.
Editor de texto simples usa uma tecnologia mais antiga do navegador. Funciona nos ambientes suportados hoje, mas será testado manualmente (não só automaticamente) antes de cada entrega, porque esse tipo de tecnologia varia sutilmente entre navegadores.

O que fica de fora deste pacote

O quadro Kanban em si, o contexto por tarefa/cartão, o anexo de arquivos, e a geração de arquivos de resumo — cada um é o próximo pacote da sequência (kanban-3-niveis → kanban-card-contexto-arquivos → kanban-pipeline-featdevelop).
